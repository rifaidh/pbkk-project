## 1. Jelaskan perbedaan aplikasi desktop dengan aplikasi lain. Mengapa masih dibutuhkan?

Aplikasi desktop adalah aplikasi yang diinstal dan berjalan langsung di komputer atau laptop pengguna. Contohnya adalah Visual Studio, Microsoft Word, Microsoft Excel, dan Microsoft PowerPoint. Berbeda dengan aplikasi web yang diakses melalui browser dan umumnya memerlukan koneksi ke server untuk menggunakan fitur atau mengakses data tertentu.

Aplikasi desktop masih dibutuhkan karena memiliki kelebihan dari segi performa dan integrasi dengan perangkat keras (*hardware*), seperti kamera, mikrofon, dan GPU. Selain itu, beberapa aplikasi desktop dapat digunakan secara offline tanpa harus selalu terhubung ke server.

## 2. Tuliskan problem yang akan diselesaikan oleh aplikasi yang kamu buat. Definisikan fitur aplikasi yang merupakan solusi dari problem tersebut.

| Problem | Fitur | 
|---|---|
| Data peserta tersebar di spreadsheet, formulir, atau dokumen terpisah sehingga sulit dikelola dan berisiko hilang atau terduplikasi. | **Participant & Registration Management:** Mengelola data peserta, pendaftaran, dan status registrasi dalam satu sistem. |
| Penjadwalan pertandingan sulit dikoordinasikan karena banyak pertandingan dan venue yang harus diatur secara bersamaan. | **Visual Match Scheduler:** Mengatur jadwal pertandingan, venue, dan staf yang bertugas, serta mendeteksi bentrokan jadwal dan penggunaan sumber daya lainnya. |
| Pembuatan bracket secara manual memakan waktu dan rentan terhadap kesalahan. | **Automatic Bracket Generator:** Membuat bracket secara otomatis dengan berbagai format serta mendukung pengacakan (*drawing*). |
| Proses check-in peserta memakan waktu lama karena dilakukan secara manual. | **QR Check-in Attendance:** Mempercepat proses check-in peserta melalui pemindaian kode QR untuk mencatat kehadiran. |
| Pencatatan skor secara manual berpotensi menimbulkan keterlambatan dalam pembaruan hasil pertandingan. | **Live Match Scoring:** Memungkinkan pencatatan skor dan pembaruan status pertandingan secara langsung. |
| Penghitungan poin dan penyusunan klasemen sulit dilakukan secara manual. | **Standings Calculation:** Menghitung perolehan poin secara otomatis dan mengurutkan peringkat klasemen berdasarkan perolehan poin. |
